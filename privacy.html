Privacy Policy

Amazon Hunter Shorts Uploader · Effective date: November 17, 2026

1. About this application

Amazon Hunter Shorts Uploader ("the App") is an internal automation tool operated by the owner of the YouTube channel "아마존 사냥꾼" (Amazon Hunter). It is used only by its owner to schedule uploads of short videos to the owner's own YouTube channel and to read that channel's performance statistics. The App is not offered to the public and has no other users.

The App uses YouTube API Services. By using the App you also agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

2. Data the App accesses

With the channel owner's authorization (Google OAuth), the App may access:

  • Basic channel information of the authorized channel (channel ID, title)
  • Videos uploaded by the App: title, description, tags, privacy/scheduled publish settings, thumbnails
  • Comments the App posts on the owner's own videos
  • Statistics and YouTube Analytics for the owner's own videos (views, likes, comments, average view duration, average view percentage, subscribers gained)

Using an API key (no user authorization), the App also reads public information about popular YouTube Shorts (title, description excerpt, tags, duration, view/like/comment counts, channel subscriber counts, thumbnails) for trend research.

The App does not access any data of other YouTube users' accounts, and does not collect personal information from viewers.

3. How the data is used

  • Uploading and scheduling the owner's own videos, setting thumbnails, and posting a comment on those videos
  • Measuring the performance of the owner's own videos and writing internal weekly reports
  • Analyzing public trends (titles, lengths, thumbnail styles) to plan the owner's own content

Data is never sold, used for advertising, or shared with third parties.

4. Storage and retention

  • OAuth credentials (refresh token, client ID and secret) are stored only as encrypted GitHub Actions Secrets and on the owner's computer. They are never committed to source code.
  • Statistics about the owner's own videos are stored in the owner's private GitHub repository and kept while the owner's authorization remains in place.
  • Public information about other channels' videos collected for trend research is kept for no longer than 30 days and is then deleted or refreshed.

5. Revoking access and deleting data

Access can be revoked at any time from the Google Account permissions page: https://myaccount.google.com/permissions. After revocation the App can no longer access the channel, and data stored by the App is deleted on request within 7 days.

1. 애플리케이션 소개

Amazon Hunter Shorts Uploader(이하 "앱")는 유튜브 채널 "아마존 사냥꾼" 운영자가 직접 사용하는 내부 자동화 도구입니다. 운영자 본인 채널에 숏츠 영상을 예약 업로드하고, 본인 채널의 성과 통계를 조회하는 용도로만 사용하며 다른 사용자에게 제공하지 않습니다.

이 앱은 YouTube API 서비스를 사용합니다. 앱 사용 시 YouTube 서비스 약관이 함께 적용되며, Google의 데이터 처리는 Google 개인정보처리방침을 따릅니다.

2. 접근하는 데이터

  • 운영자가 승인(Google OAuth)한 채널의 기본 정보(채널 ID, 이름)
  • 앱이 업로드한 영상의 제목·설명·태그·공개 예약 설정·썸네일
  • 운영자 본인 영상에 앱이 작성하는 댓글
  • 운영자 본인 영상의 통계 및 YouTube 분석 데이터(조회수, 좋아요, 댓글 수, 평균 시청 시간·비율, 구독자 증가)
  • 트렌드 조사를 위해 API 키로 조회하는 인기 숏츠의 공개 정보(제목, 설명 일부, 태그, 길이, 조회수 등, 채널 구독자 수, 썸네일)

다른 유튜브 사용자의 계정 데이터에는 접근하지 않으며, 시청자의 개인정보를 수집하지 않습니다.

3. 이용 목적

본인 영상 업로드·예약·썸네일 지정·댓글 작성, 본인 영상 성과 측정과 내부 주간 리포트 작성, 본인 콘텐츠 기획을 위한 공개 트렌드 분석에만 사용합니다. 데이터를 판매하거나 광고에 쓰거나 제3자와 공유하지 않습니다.

4. 보관 및 파기

  • OAuth 인증 정보(리프레시 토큰, 클라이언트 ID·비밀번호)는 암호화된 GitHub Actions Secrets와 운영자 컴퓨터에만 보관하며, 소스 코드에 넣지 않습니다.
  • 본인 영상 통계는 운영자의 비공개 GitHub 저장소에 저장하며, 운영자의 승인이 유지되는 동안 보관합니다.

Google 계정 권한 페이지(https://myaccount.google.com/permissions)에서 언제든 앱의 접근 권한을 철회할 수 있습니다. 철회 후에는 앱이 채널에 접근할 수 없으며, 요청 시 앱이 저장한 데이터를 7일 이내에 삭제합니다.
